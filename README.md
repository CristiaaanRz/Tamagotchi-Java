# Simulador de Tamagotchis Interactivos

Proyecto desarrollado en Java para la materia de Programación Orientada a Objetos de la Universidad Autónoma de Baja California (UABC).

## Descripción

El programa permite crear y cuidar mascotas virtuales de cuatro tipos: perro, gato, muñeca y cuyo.

Cada mascota tiene atributos como hambre, energía, felicidad y edad. El usuario puede alimentarlas, jugar con ellas, hacerlas dormir y realizar acciones especiales dependiendo de su especie.

Las mascotas pueden cambiar de estado de ánimo, envejecer y morir por descuido o vejez.

## Características

- Creación de diferentes tipos de mascotas.
- Alimentos y juegos específicos para cada especie.
- Comportamientos especiales de cada Tamagotchi.
- Sistema de hambre, energía y felicidad.
- Envejecimiento y muerte de las mascotas.
- Interfaz gráfica desarrollada con JavaFX.
- Organización mediante el patrón Modelo-Vista-Controlador (MVC).

## Tecnologías utilizadas

- Java
- JavaFX
- Maven
- Programación orientada a objetos

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Esperar a que Maven cargue las dependencias.
4. Ejecutar la clase `Main.java`.

El programa inicia con la interfaz gráfica. También se puede utilizar la versión de consola pasando el argumento `--consola`.
